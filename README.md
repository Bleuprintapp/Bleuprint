# Bleuprint

The public Bleuprint website.

## Pages

- `index.html` — public homepage, services, proof, and $199 diagnosis pathway
- `portfolio.html` — native responsive portfolio with supplied videos and analytics
- `review.html` — direct client review form with clear publishing permissions
- `diagnosis.html` — self-guided 10-question diagnosis
- `consult.html` — $199 diagnosis booking page

The site is plain HTML, CSS, and JavaScript. It is ready to deploy as a static site.

## Forms and booking

- Booking uses `https://calendly.com/kalenagardner07/30min`.
- Diagnosis, consultation, and review form submissions are sent through FormSubmit to the Bleuprint inbox configured in the source.

## Privacy

Do not add client folders, founder workspaces, private strategy documents, or exports to this public repository.
